# وثيقة التسليم للمرحلة التالية (Handoff Document — Phase 1 to Phase 2)

> **مرحباً بك أيها الوكيل 2 (Agent 2):**
> هذه الوثيقة هي **أول ملف يجب أن تقرأه**. تم إنجاز وتثبيت بنية المرحلة الأولى بالكامل بنجاح. هذا الدليل يوضح لك الحالة الراهنة، ما تم إنجازه، المشاكل المعروفة، وخارطة طريقك للبدء الفوري دون تشتت.

## 1) الحالة الراهنة للمشروع (Current State)

- **الحزمة التقنية:** Next.js 15 App Router + React 19 + TypeScript الصارم + Tailwind CSS 4 + Motion.
- **جودة الكود:**
  - `npm run build` ينجح بنسبة 100% بدون أي تحذيرات أو أخطاء.
  - `npm run lint` ينجح بنسبة 100% مع التزام كامل بقواعد React 19 الحديثة.
- **الكود القديم:** محفوظ في مجلد `legacy/` للقراءة والاسترشاد فقط، ومستبعد من البناء والفحص.
- **نظام التصميم المعتمد (Orbit Design System):** نظام تصميم «مدار» الهادئ والواثق المعتمد بعد إعادة التصميم (DEC-007). يعتمد على خلفية `--bg` (#F4F6F8)، حبر داكن `--ink` (#0B1220)، ولون إشارة ليموني فاقع `--signal` (#C6F24E) مع خطوط Readex Pro و IBM Plex Sans Arabic المستضافة محلياً. خريطة المكونات الكاملة متاحة حياً في: `/design`.
- **صدفة التطبيق (App Shell):** شريط تنقل سفلي أصلي طائف (5 تبويبات بكبسولة ليمونية)، ترويسة ذكية، وأزرار بوابة `t.net` تعمل بفاعلية، وجميع الشاشات تعمل بحالات صادقة واحترافية بدون إيموجي.
- **بنية PWA:** تطبيق ويب تقدمي قابل للتثبيت فوراً على أندرويد وiOS وسطح المكتب، يدعم التصفح غير المتصل (Offline Precache)، ويحتوي على نظام إشعار تحديث نظيف.

## 2) ما يعمل حالياً (What Works)

1. **الرئيسية (`HomeView`):**
   - أزرار الانتقال المباشر لبوابة الهوتسبوت: `http://t.net` والرابط البديل `http://10.5.50.1/login`.
   - زر فحص رصيد الكرت: `http://t.net/status`.
   - تنبيه ذكي يشرح ضرورة الاتصال بواي فاي الشبكة لفتح بوابات ميكروتك.
   - بطاقات إعلانات الشبكة، فحص السرعة التفاعلي، ومسابقة الولاء، وزر الدعم المباشر بواتساب.
2. **الباقات ومعلومات الكروت (`PackagesView`):**
   - استعراض فئات الكروت الأربع بأسعارها المعتمدة بالريال اليمني (200، 500، 1000، 4000 VIP) وتفاصيل الرصيد والوقت والصلاحية وأقصى سرعة.
   - فلترة تفاعلية حسب فئة الكرت (ساعات، يومية، أسبوعية، شهرية VIP).
   - زر «طلب الكرت عبر واتساب» يفتح رسالة مخصصة مسبقاً لكل فئة.
   - ورقة سفلية (Bottom Sheet) تستعرض نقاط التوزيع الحالية مع تنبيه صريح بكونها بيانات أولية.
3. **المزيد والدعم (`MoreView`):**
   - قنوات الدعم الرسمية (واتساب، اتصال هاتفي مباشر، تيليجرام، فيسبوك).
   - بطاقة تثبيت التطبيق الذكية مع دليل تفصيلي لمستخدمي الآيفون وSafari.
   - تذييل المطور الرسمي: م/ مصطفى حسان — Samtec AI بروابط الموقع وواتساب المطور المباشرة.
   - رابط صفحة نظام التصميم `/design`.
4. **فحص السرعة (`SpeedTestModal`):**
   - فحص فعلي حقيقي لزمن استجابة الشبكة (Real Round-trip Ping) وحساب التذبذب (Jitter) بالمللي ثانية، مع إيضاح شفاف بأن فحص سرعة التحميل والرفع الشامل سيتم ربطه في المرحلة 2.
5. **مسابقة الانتماء (`LoyaltyPreviewModal`):**
   - شرح شفاف لقواعد المسابقة (تجميع 10 كروت منتهية لدخول عجلة الحظ) تمهيداً لبنائها في المرحلة 3.
6. **خدمة PWA والتخزين المؤقت:**
   - بيان PWA رسمي معتمد `public/manifest.webmanifest`.
   - خدمة `sw.js` تخزن الصدفة مسبقاً وتوفر صفحة `offline.html` راقية وتدير التحديث بأمان.

## 4) المشاكل المعمارية المعروفة وكيفية حلها (Known Architectural Issues)

1. **مشكلة المحتوى المختلط (Mixed Content Security):**
   - **الواقع:** التطبيق في الإنتاج يُخدَّم عبر `HTTPS` (`https://talqanet.vercel.app`)، بينما عناوين السيرفر المحلي وميكروتك هي `HTTP` على شبكة داخلية (`http://192.168.50.2:8096`, `http://192.168.50.2:8888`, `http://t.net`).
   - **الحل:** تجنب استخدام iframes أو fetch مباشر من HTTPS لـ HTTP محلي. اعتمد على روابط تنقل خارجية بـ `target="_blank"`، أو قم بفحص اتصال خفيف عبر WebRTC أو `Image.onerror` لاكتشاف هل العميل داخل شبكة LAN قبل محاولة تحميل وسائط HLS، وقدم رسالة واضحة: («متاح داخل شبكة طلقة نت فقط»).

2. **قواعد استخراج البيانات من الكود القديم:**
   - الكود القديم موجود في `legacy/`. استعن به فقط كمرجع للأكواد الحسابية ولا تنقل تصميماته القديمة (الداكنة/النيون) المرفوضة من صاحب المشروع.

6. **الخطوة السادسة:** في نافذة فحص السرعة `SpeedTestModal`، أضف فحص التحميل الفعلي (عن طريق تنزيل كتلة بيانات محسوبة وقياس بايت/ثانية فعلياً).
